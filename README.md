# Sổ tay JPD113

Web tổng hợp kiến thức và lộ trình học môn **JPD113 – Tiếng Nhật sơ cấp 1 (A1.1)**, giáo trình できる日本語 初級, bài 1–3.

- **Lộ trình**: 20 slot chia 5 giai đoạn, tự đánh dấu slot đã qua và buổi học tới theo ngày hiện tại.
- **Bảng chữ**: Hiragana/Katakana, âm đục, âm ghép, quy tắc âm dài – âm ngắt.
- **Bài 1–3**: ngữ pháp, từ vựng (có nút ẩn nghĩa để tự kiểm tra), kanji, số đếm, ngày tháng, giờ.
- **Thi nói**: cấu trúc đề, thang điểm, câu hỏi mẫu kèm gợi ý trả lời.

Trang tĩnh HTML/CSS/JS, không cần build. Chạy thử: mở `index.html` trong trình duyệt.
Sửa nội dung trong `data.js`.
